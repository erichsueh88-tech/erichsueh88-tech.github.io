  • 資料保存在 LocalStorage，支援檔案上傳轉 Base64 保存與完整還原下載。

🚀 升級路徑 A：本機伺服器 (Node.js Express / Python Flask)

  • 架設輕量內網服務，實體檔案存於伺服器硬碟，解除 LocalStorage 限制。
  • 自動生成圖面與 BOM 比對 PDF 報表。

🏢 升級路徑 C：企業級 SQL 資料庫與權限整合

  • 搭配 MySQL / PostgreSQL，支援多使用者即時同步與 Audit Log 變更歷程。
  • 整合企業 LDAP / AD 單一簽入 (SSO) 與研發/品保/業務多級簽核工作流。
